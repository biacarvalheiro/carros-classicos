# Garagem Clássica

SPA sobre carros clássicos, feita com React e Vite. Projeto da avaliação 1 (hackathon de 8 horas).

## Tecnologias

- React
- Vite
- react-router-dom

## Como rodar

```bash
npm install
npm run dev
```

O site abre em http://localhost:5173

## Estrutura

```
src/
  components/   Header, Footer, Card, BackButton
  pages/        Home, Categoria
  data/         carros.json, categorias.json
public/
  images/       fotos dos carros
```
